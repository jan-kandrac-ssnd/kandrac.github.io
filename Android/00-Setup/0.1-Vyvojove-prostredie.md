# 0.1 Inštalácia vývojového prostredia

Pre programovanie **Android** alebo **Kotlin Multiplatform** aplikácií budeme používať vývojové prostredie
**Android Studio**. Android Studio si môžeš stiahnuť na
[oficiálnych stránkach Android Studia](https://developer.android.com/studio).

Jeho inštalácia na Windows a Mac platforme je pomerne priamočiara, Linux môže byť trocha tricky na nastavenie.
V návodoch nižšie uvádzam postupy, ktoré sp napísané na [oficiálnej stránke](https://developer.android.com/studio/install).

## Windows

Len prepisujem oficiálny návod:

1. Ak stiahneš `EXE` súbor (odporúčané), nainštaluj ho dvojklikom
2. Ak stiahneš `Zip` súbor
   1. Rozbaľ `Zip` súbor.
   2. Skopíruj zložku **android-studio** do zložky **Program Files**.
   3. Otvor zložku **bin** v zložke **android-studio**.
   4. Spusť **studio64.exe** (for 64-bit machines) or **studio.exe** (for 32-bit machines).
   5. Nasleduj **Setup Wizard** v **Android Studiu** a nainštaluj odporúčané SDK balíky.

## Mac

Pre nainštalovanie Android Studia na Macu, postupuj nasledovne:

1. Otvor Android Studio `DMG` file.
2. Presuň Android Studio do zložky **Applications**, a spusť Android Studio.
3. Ak existovala pôvodná inštalácia, zvoľ či chceš alebo nechceš importovať nastavenia z predchádzajúceho Android Studia, a stlač `OK`.
4. Dokonči Android Studio **Setup Wizard**. Jeho absolvovanie pokrýva aj stiahnutie Android SDK komponentov potrebných pre vývoj.

## Linux

> **Note:** Linux machines with ARM-based CPUs aren't currently supported

Pre inštaláciu Android Studia na Linuxe, postupuj nasledovne:

1. Rozbaľ stiahnutý `.tar.gz` súbor a presuň ho na správne miesto. Obvykle to je `/usr/local/` pre aktuálneho
používateľa alebo `/opt/` pre zdieľaných používateľov. Pre 64-bitovú verziu Linuxu, najprv nainštaluj [potrebné knižnice pre 64-bitové zariadenia](#knižnice-potrebné-pre-64-bitové-verzie-linuxu).
2. Pre spustenie Android Studia, otvor terminál, vojdi do zložky `android-studio/bin/`, a spusti `studio`.
3. Ak existovala pôvodná inštalácia, zvoľ či chceš alebo nechceš importovať nastavenia z predchádzajúceho Android Studia, a stlač `OK`.
4. Dokonči Android Studio **Setup Wizard**. Jeho absolvovanie pokrýva aj stiahnutie Android SDK komponentov potrebných pre vývoj.

### Knižnice potrebné pre 64-bitové verzie Linuxu

64-bit verzia Ubuntu, potrebuje nainštalovať niektoré 32-bitové knižnice pomocou tohto príkazu:

```bash
sudo apt-get install libc6:i386 libncurses5:i386 libstdc++6:i386 lib32z1 libbz2-1.0:i386
```

V prípade 64-bitovej verzie Fedory:

```bash
sudo yum install zlib.i686 ncurses-libs.i686 bzip2-libs.i686
```
