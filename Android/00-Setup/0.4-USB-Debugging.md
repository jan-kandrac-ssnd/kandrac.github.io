# 0.4 USB debugging

Ďalšou alternatívou je zapnutie USB debuggingu na tvojom telefóne a spúšťať tvoju aplikáciu priamo na fyzickom telefóne.

To vieme spraviť troma krokmi:
1. Povoliť [developerské nastavenia](https://developer.android.com/studio/debug/dev-options)
2. Povoliť [USB Debugging](https://developer.android.com/studio/debug/dev-options#debugging)
3. Povoliť konkrétnemu počítaču komunikovať so zariadením prostredníctvom USB debugging

## Zapnutie Dev módu

1. Na fyzickom telefóne musíš v nastaveniach nájsť _"Build Number"_ alebo _"Číslo zostavy"_
2. Tapni "Build Number" 7x, kým neuvidíš hlášku: _"You are now a developer!"_ alebo _"Teraz ste vývojár!"_
3. Vráť sa na predchádzajúcu obrazovku, kde môžeš nájsť novú položku menu s názvom **"Developer Options"** alebo **"Nastavenia vývojára"**

Číslo zostavy sa môže nachádzať na rôznych miestach v závislosti od tvojho telefónu:

Napríklad:

| Zariadenie                  | Umiestnenie                                                                                                                                   |
|-----------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| Google Pixel                | Settings > About phone > Build number                                                                                                         |
| Google Pixel Watch          | Settings > System > About > Versions > Build number                                                                                           |
| Samsung Galaxy S8 and later | Settings > About phone > Software information > Build number                                                                                  |
| LG G6 and later             | Settings > About phone > Software info > Build number                                                                                         |
| HTC U11 and later           | Settings > About > Software information > More > Build number or Settings > System > About phone > Software information > More > Build number |
| OnePlus 5T and later        | Settings > About phone > Build number                                                                                                         |

## Povolenie USB Debugging

Na niektorej obrazovke v nastaveniach sa ti zobrazí menu položka s názvom **"Developer Options"** alebo **"Nastavenia vývojára"**

1. Otvor zložku **"Developer Options"** alebo **"Nastavenia vývojára"**
2. Nájdi switch s názvom **ADB debugging** alebo **USB debugging**
3. Povoľ **USB debugging**

## Povolenie PC komunikovať so zariadením cez USB debugging

Jedná sa o nebezpečné nastavenie. Po povolení USB debugging by totiž útočník mohol ľahko získať plnú kontrolu nad tvojim
zariadením. Preto musíš manuálne cez telefón povoliť danému PC aby mohol s tvojim zariadením komunikovať.

1. Pripoj telefón k PC pomocou dátového kábla
2. Mal by sa ti zobraziť dialóg s MAC adresou PC ku ktorému si telefón pripojil
3. Ak danému PC dôveruješ, povoľ v telefóne ladenie cez USB s týmto PC
