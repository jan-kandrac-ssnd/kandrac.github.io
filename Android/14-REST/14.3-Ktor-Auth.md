# 14.3 Ktor Client - autentifikácia

Autentifikácia je obrovská téma a nebudem ju schopný úpkne pokryť. Prikladám ale odkazy na oficiálnu dokumentáciu:
- [Úvodné slovko v autentifikácii](https://ktor.io/docs/client-auth.html)
- [Basic Auth](https://ktor.io/docs/client-basic-auth.html#configure)
- [Digest Auth](https://ktor.io/docs/client-digest-auth.html)
- [Beared Auth](https://ktor.io/docs/client-bearer-auth.html)

Pre autentifikáciu používame `Auth` plugin z nasledujúcej závislosti:

```kotlin
dependencies {
    implementation("io.ktor:ktor-client-auth:3.5.2")    // ak chceme autentifikaciu
}
```

Vrámci `HttpClient`-a potom môžeme nastaviť autentifikáciu pomocou `Auth` pluginu a definovaním jednej z metód `basic`,
`digest` alebo `bearer` auth:

```kotlin
install(Auth) {
    basic {}
    digest {}
    bearer {}
}
```

A potom postupovať jedným z návodou priložených v úvode tejto kapitoly. Ak vieš presne, ktorý typ autentifikácie chceš
použiť, poraď sa s AI.
