# 16.1 Preferences DataStore

DataStore slúži na perzistovanie malých dát. Perzistovanie znamená, že dáta, ktoré si do DataStore uložím, zostanú k
dispozícii aj po aplikácii sa ukončí/reštartuje. Ukladáme tam veci ako:

1. nastavenia aplikácie
2. autentikačné tokeny (dáta prihláseného používateľa)
3. informáciu o absolvovaní onboardingu a pod.

Dáta sa ukladajú štýlom kľúč hodnota. Teda napríklad pod kľúčom `"DARK_MODE` bude uložená hodnota `true` alebo `false`.
Vždy keď si vyžiadam hodnotu pod kľúčom `"DARK_MODE"`, DataStore vráti hodnotu, ktorá tam bola uložená naposledy.
Dáta z DataStore Preferences sa za normálnych okolností neprenášajú medzi inštaláciami aplikácie.

## Preferences DataStore Setup

Pridáme závislosť do súboru `app/build.gradle.kts`:

```kotlin
dependencies {
    implementation("androidx.datastore:datastore-preferences:1.2.1")
}
```

### Vytvorenie kľúčov

Kľúče definujeme tak, že priamo podľa kľúča vieme zistiť, aký typ dát sa nachádza v hodnote. Tieto kľúče ako aj zvyšok
konfigurácie odporúčam držať v samostatnom súbore. Napr. `preferences.kt`. Zopár praktických príkladov:

```kotlin
import androidx.datastore.preferences.core.Preferences
import androidx.datastore.preferences.core.booleanPreferencesKey
import androidx.datastore.preferences.core.intPreferencesKey
import androidx.datastore.preferences.core.longPreferencesKey
import androidx.datastore.preferences.core.stringPreferencesKey
import androidx.datastore.preferences.preferencesDataStore

val EXAMPLE_COUNTER = intPreferencesKey("example_counter")
val EXAMPLE_TOKEN = stringPreferencesKey("example_token")
val EXAMPLE_ONBOARDING_PASSED = booleanPreferencesKey("example_onboarding_passed")
val EXAMPLE_LAST_UPDATE_MILLIS = longPreferencesKey("example_last_update_millis")
```

### Získanie Preferences DataStore

DataStore preferences sú na pozadí uložené v nejakom súbore. Keď chceme získať `DataStore` pre prácu s preferences,
použijeme `preferencesDataStore` s názvom tohto súboru (názov je na nás). Tento súbor sa viaže na `Context` našej
aplikácie, preto uvádzam oproti tutoriálu jednu pomocnú funkciu navyše:

```kotlin
val Context.dataStore: DataStore<Preferences> by preferencesDataStore(name = "settings")

val dataStore @Composable get() = LocalContext.current.dataStore
```
