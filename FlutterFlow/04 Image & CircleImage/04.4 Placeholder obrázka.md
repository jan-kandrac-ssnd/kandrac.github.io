## 04.4 Placeholder obrázka

Placeholder obrázka je náhradné zobrazenie, ktoré udrží kartu použiteľnú pri neprístupnej URL alebo počas načítavania obrázka; použite ho pri dynamických URL z API či Firestore.

--- Dopln obrazok ---

### Postup vo FlutterFlow

1. Vytvorte `Stack` s rozmermi `160 × 100` a ako spodné dieťa vložte Container so sivou farbou `#E5E7EB` a Icon `image_outlined`.
2. Nad Container pridajte Image a jeho URL nastavte cez `Set from Variable` na pole `imageUrl`.
3. Na Image nastavte `Conditional Visibility`: zobrazujte ho iba keď `imageUrl` nie je prázdne.
4. Pri prázdnom `imageUrl` zostane viditeľný sivý Container s ikonou; overte oba stavy v Test Mode.

--- Dopln obrazok ---

### Tip a častá chyba

Tip: FlutterFlow Image widget nemá univerzálnu vlastnosť pre fallback pri HTTP chybe; pri známej chýbajúcej URL riešte rezervu Stackom a Conditional Visibility.

Častá chyba: Conditional Visibility skryje Image pri prázdnej hodnote, ale bez spodného Containeru vznikne prázdne miesto namiesto náhradného vizuálu.

### Overenie

- [ ] Pri prázdnom `imageUrl` skontrolujem, že sa zobrazí sivý placeholder s ikonou.
- [ ] Po nastavení neprázdneho `imageUrl` overím, že placeholder nahradí Image widget.
