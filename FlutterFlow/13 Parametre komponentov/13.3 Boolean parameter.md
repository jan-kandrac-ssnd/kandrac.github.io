## 13.3 Boolean parameter

Boolean parameter prepne stav komponentu hodnotou true alebo false; použite ho pre viditeľnosť odznaku alebo aktívny štýl.

--- Dopln obrazok ---

### Postup vo FlutterFlow

1. Otvorte komponent `ProductCard` a v `Component Parameters` pridajte parameter `title` typu `String`.
2. Text widgetu nastavte cez `Set from Variable > Component Parameters > title`.
3. Pridajte `isFavorite` typu Boolean pre Conditional Visibility alebo `onPressed` typu Action pre akciu Buttonu.
4. Na HomePage vložte komponent a nastavte `title` na `Espresso`.

--- Dopln obrazok ---

### Tip a častá chyba

Tip: Callback parameter umožní komponentu oznámiť kliknutie rodičovskej stránke bez priamej navigácie v komponente.

Častá chyba: Component Parameter nie je globálna hodnota; každá inštancia môže dostať iný vstup.

### Overenie

- [ ] Skontrolujem, že Boolean parameter `isFavorite` riadi podmienenú viditeľnosť zvoleného widgetu.
- [ ] Po prepnutí `isFavorite` overím zobrazenie opačného stavu komponentu.
