## 14.3 Android konfigurácia

Android konfigurácia pridá Android package name a Firebase súbor do projektu; použite ju pred testovaním Firebase v Android aplikácii.

--- Dopln obrazok ---

### Postup vo FlutterFlow

1. V FlutterFlow otvorte `Settings & Integrations > Firebase` a kliknite na `Connect`.
2. Vytvorte alebo vyberte Firebase projekt s rovnakým Android package name a webovou konfiguráciou.
3. Dokončite požadovanú Android alebo Web konfiguráciu podľa pokynov FlutterFlow.
4. Spustite Test Mode a overte v Firebase konzole vznik testovacej Authentication alebo Firestore požiadavky.

--- Dopln obrazok ---

### Tip a častá chyba

Tip: Android package name a iOS bundle ID musia presne zodpovedať identifikátorom v Project Setup.

Častá chyba: Stiahnutý konfiguračný súbor z iného Firebase projektu spôsobí, že aplikácia zapisuje alebo prihlasuje do nesprávneho projektu.

### Overenie

- [ ] Skontrolujem zhodu Android package name vo FlutterFlow a Firebase projekte.
- [ ] Overím, že Android konfigurácia dokončená podľa pokynov umožní testovaciu Firebase požiadavku.
