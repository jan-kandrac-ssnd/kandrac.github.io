## 15.1 Enable Email Password

Enable Email Password zapne provider e-mail/heslo vo Firebase Authentication; použite ho pred registráciou a loginom.

--- Dopln obrazok ---

### Postup vo FlutterFlow

1. Na SignUpPage pridajte TextField `emailField` a `passwordField`; pri hesle zapnite `Obscure Text`.
2. Vyberte Button `Vytvoriť účet`, otvorte `Actions` a pridajte `Authentication > Create Account`.
3. Pre `Email` vyberte `Widget State > emailField` a pre `Password` vyberte `Widget State > passwordField`.
4. Zapnite `Create User Document`, vyberte kolekciu `users` a v Test Mode založte nový e-mailový účet.

--- Dopln obrazok ---

### Tip a častá chyba

Tip: V Create User Document pridajte napríklad pole `createdTime` s hodnotou `Current Timestamp`.

Častá chyba: Režim Create Account zlyhá, ak v Firebase Authentication nie je zapnutý provider Email/Password.

### Overenie

- [ ] Skontrolujem, že provider Email/Password je v Firebase Authentication povolený.
- [ ] Overím, že formulár môže odoslať registráciu e-mailom a heslom.
