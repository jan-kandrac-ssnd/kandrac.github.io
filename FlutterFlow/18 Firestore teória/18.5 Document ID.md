## 18.5 Document ID

Document ID jednoznačne určuje Firestore dokument; použite vlastné ID `espresso` pre čitateľnú URL alebo automatické ID pre nové záznamy.

--- Dopln obrazok ---

### Postup vo FlutterFlow

1. V `Firestore > Firestore Collections` vytvorte kolekciu `products`.
2. Pridajte dokument s ID `espresso` a poľami `name` (String) a `price` (Double).
3. Ak lekcia rieši subcollection alebo ID, vytvorte `products/espresso/reviews` alebo ponechajte vlastné ID.
4. Otvorte Firestore konzolu a overte presnú cestu aj typy uložených polí.

--- Dopln obrazok ---

### Tip a častá chyba

Tip: Kolekcie pomenujte v množnom čísle, napríklad `products` a `orders`, aby boli dotazy čitateľné.

Častá chyba: String `9.90` nie je číslo Double, preto sa nedá správne radiť ani sčítať.

### Overenie

- [ ] Skontrolujem, že dokument má nastavené očakávané ID, napríklad `espresso`.
- [ ] Overím, že ID dokumentu je odlišné od jeho polí `name` a `price`.
