## 19.2 User schema

User schema určuje polia dokumentu používateľa; použite `displayName`, `photoUrl` a `createdTime` pre profil.

--- Dopln obrazok ---

### Postup vo FlutterFlow

1. V `Firestore > Firestore Collections` vytvorte alebo otvorte kolekciu `users`.
2. Do schémy pridajte `displayName` (String), `photoUrl` (String) a `createdTime` (DateTime).
3. Pri registračnej akcii zapnite `Create User Document` a namapujte displayName z Widget State.
4. Na profile pridajte query `Current User Document` a zobrazte pole `displayName` v Text widgete.

--- Dopln obrazok ---

### Tip a častá chyba

Tip: Dokument používateľa ukladajte s UID z Authentication, aby `Current User Document` našiel správny záznam.

Častá chyba: Profilové polia nepatria do Firebase Authentication; treba ich zapísať do dokumentu `users` vo Firestore.

### Overenie

- [ ] Skontrolujem, že schéma `users` obsahuje `displayName`, `photoUrl` a `createdTime`.
- [ ] Overím správne typy String pre `displayName` a `photoUrl` a DateTime pre `createdTime`.
