## 20.1 Document Reference

Document Reference uchováva typovaný odkaz na Firestore dokument; použite ho na väzbu objednávky s používateľom.

--- Dopln obrazok ---

### Postup vo FlutterFlow

1. V schéme kolekcie `orders` pridajte pole `customerRef` typu `Document Reference` s kolekciou `users`.
2. Pri `Create Document` nastavte customerRef na `Authenticated User > Reference`.
3. Pri dotaze orders pridajte filter `customerRef` `Is Equal To` aktuálnej user reference.
4. V Test Mode vytvorte objednávku a overte, že sa zobrazí iba prihlásenému používateľovi.

--- Dopln obrazok ---

### Tip a častá chyba

Tip: Reference zachováva väzbu aj keď dokument nemá predvídateľné ID; neukladajte duplicitne UID ako obyčajný String bez dôvodu.

Častá chyba: Porovnanie Document Reference s textovým UID nevráti žiadne výsledky, pretože ide o rozdielne typy.

### Overenie

- [ ] Skontrolujem, že `customerRef` ukladá referenciu na dokument aktuálneho používateľa.
- [ ] Overím, že `customerRef` nie je uložené ako textové UID.
