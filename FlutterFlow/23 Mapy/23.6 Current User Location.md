## 23.6 Current User Location

Current User Location načíta polohu zariadenia a zobrazí ju na mape; použite ho pre navigáciu alebo doručenie.

--- Dopln obrazok ---

### Postup vo FlutterFlow

1. V `Settings & Integrations > Google Maps` vložte platný Google Maps API key.
2. Pridajte `Google Map` widget na stránku a nastavte výšku `320`.
3. Nastavte Initial Location na Bratislava (`48.1486`, `17.1077`) alebo na hodnotu z Firestore.
4. Pridajte marker alebo zapnite `Current User Location` a otestujte mapu na zariadení.

--- Dopln obrazok ---

### Tip a častá chyba

Tip: Pre polohu z Firestore používajte pole typu LatLng, nie dva neprepojené textové reťazce.

Častá chyba: Mapa zostane prázdna, ak API key nemá povolené Maps SDK a príslušné obmedzenie pre aplikáciu.

### Overenie

- [ ] Po udelení povolenia skontrolujem zobrazenie aktuálnej polohy používateľa na mape.
- [ ] Overím, že bez povolenia polohy aplikácia vyžiada potrebné oprávnenie.
