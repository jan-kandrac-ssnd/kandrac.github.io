## 25.7 POST

POST odošle JSON dáta API a typicky vytvorí nový záznam; použite ho pre objednávku alebo formulár.

--- Dopln obrazok ---

### Postup vo FlutterFlow

1. V `Backend > API Calls` vytvorte API Call `GetProducts` s metódou `GET` a URL `https://dummyjson.com/products`.
2. Kliknite na `Test API Call`, uložte odpoveď a v `Response & Test` označte JSON polia `products`, `title` a `price`.
3. Pre GET pridajte Query Parameter `limit=10`; pre chránené API pridajte Header `Authorization`; pri POST nastavte JSON Body.
4. V UI pridajte ListView, zapnite `Generate Dynamic Children` z `GetProducts > products` a Text nastavte cez `Set from Variable > API Response > title`.

--- Dopln obrazok ---

### Tip a častá chyba

Tip: Najprv uložte úspešný Test API Call, až potom FlutterFlow ponúkne JSON fields pri Set from Variable.

Častá chyba: Cesta `products` je zoznam; Text widget musí čítať pole `title` aktuálnej položky, nie celý zoznam.

### Overenie

- [ ] Skontrolujem, že POST call odošle nastavené JSON body.
- [ ] Overím, že úspešná odpoveď potvrdí vytvorenie alebo zmenu dát.
