## 25.8 API Response v UI

API Response v UI zobrazí JSON odpoveď API callu v zozname alebo texte; použite ho, keď externé dáta majú byť viditeľné na stránke.

--- Dopln obrazok ---

### Postup vo FlutterFlow

1. Na stránke v `Backend Query` pridajte API Call `GetProducts` a vyberte call s úspešne uloženým Response Schema.
2. Pridajte `ListView`, v Properties Panel zapnite `Generate Dynamic Children` a zdroj nastavte na `GetProducts > products`.
3. Vyberte Text vnútri ListView a cez `Set from Variable > API Response > title` namapujte názov aktuálnej položky.
4. Druhý Text namapujte na `price`, spustite Test Mode a skontrolujte viac samostatných produktov.

--- Dopln obrazok ---

### Tip a častá chyba

Tip: JSON field vyberajte z kontextu aktuálnej položky dynamického ListView, aby Text dostal jeden title, nie celé pole products.

Častá chyba: Bez Generate Dynamic Children sa Text nevie opakovať pre jednotlivé objekty odpovede.

### Overenie

- [ ] Skontrolujem, že ListView zobrazí rovnaký počet položiek ako pole `products` v odpovedi API.
- [ ] Overím, že každý riadok namapuje JSON polia `title` a `price` aktuálnej položky.
