# 0.2 Inštalácia Git na Windows

Na Windows sa **Git** neinštaluje cez príkazový riadok, ale pomocou klasického grafického inštalátora.

## Postup inštalácie

1. Stiahni si inštalátor zo stránky [git-scm.com](https://git-scm.com/download/win).
2. Spusti stiahnutý súbor a prejdi inštalačným sprievodcom.
3. Pri kroku, kde sa vyberá **predvolený textový editor**, zvoľ **Notepad**.
4. Ostatné nastavenia môžeš pokojne nechať **predvolené**.
5. Dokonči inštaláciu kliknutím na **Install** a počkaj, kým sa proces skončí.

## Overenie inštalácie

Po dokončení inštalácie si over, že Git funguje. Otvor **Git Bash** (nainštaluje sa spolu s Gitom) alebo príkazový
riadok a zadaj:

```bash
git --version
```

Ak sa ti zobrazí číslo verzie (napr. `git version 2.44.0.windows.1`), inštalácia prebehla úspešne.
