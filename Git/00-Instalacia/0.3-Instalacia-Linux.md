# 0.3 Inštalácia Git na Linux

Na Linuxe sa Git zvyčajne inštaluje priamo cez **terminál** pomocou balíčkovacieho manažéra danej distribúcie.

## Postup inštalácie

1. Otvor **terminál**.
2. Podľa toho, akú distribúciu používaš, spusti príslušný príkaz:

   - **Ubuntu / Debian a odvodené distribúcie:**

     ```bash
     sudo apt-get install git
     ```

   - **Fedora a odvodené distribúcie:**

     ```bash
     sudo dnf install git
     ```

## Zmena predvoleného textového editora

Git štandardne používa ako editor **Vim**, ktorý nemusí byť pre začiatočníkov najpohodlnejší. Ak chceš namiesto neho používať iný, prehľadnejší editor (napríklad `gedit`), nastav ho príkazom:

```bash
git config --global core.editor gedit
```

Namiesto `gedit` môžeš uviesť ľubovoľný iný nainštalovaný editor, ktorý chceš používať.

## Overenie inštalácie

Na záver over, že je Git správne nainštalovaný:

```bash
git --version
```

Ak príkaz vypíše číslo verzie, inštalácia bola úspešná.
