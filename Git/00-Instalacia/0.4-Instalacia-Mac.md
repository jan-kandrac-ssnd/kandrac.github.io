# 0.4 Inštalácia Git na Mac

Na macOS máš na výber dva bežné spôsoby, ako si Git nainštalovať — cez **XCode Command Line Tools** alebo cez balíčkovací manažér **Homebrew**.

## Postup inštalácie

1. Otvor **terminál**.
2. Vyber si jeden z nasledujúcich spôsobov inštalácie:

   - **Cez XCode Command Line Tools** (jednoduchšie, stačí príkaz nižšie):

     ```bash
     xcode-select --install
     ```

   - **Cez Homebrew** (odporúčaný spôsob — Homebrew je praktický balíčkovací manažér pre macOS, ktorý sa oplatí naštudovať a používať aj na inštaláciu ďalších nástrojov):

     ```bash
     brew install git
     ```

     > Ak ešte nemáš nainštalovaný Homebrew, najprv si ho nainštaluj podľa návodu na [brew.sh](https://brew.sh/).

## Overenie inštalácie

Po dokončení inštalácie skontroluj, že Git funguje správne:

```bash
git --version
```

Ak sa zobrazí číslo verzie, Git je pripravený na použitie.
