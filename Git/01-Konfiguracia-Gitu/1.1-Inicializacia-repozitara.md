# 1.1 Inicializácia repozitára

Projekt, ktorý pracuje s Gitom, je vždy len nejaká jednoduchá zložka, v ktorej máme uložené všetky naše zdrojáky.
O tejto zložke potrebujeme Gitu povedať, aby sa ten postaral o správu jej verzií. Akonáhle Gitu povieme, že ho nejaká
zložka má používať, zložka sa stáva v Git terminológii **repozitárom** alebo skrátene "repo"-m.

Pre tých z vás, ktorí sa v príkazovom riadku veľmi nevyznajú, nebojte sa. Terminál je vojsko, ktoré poslúcha na rozkazy.
Ak oslovíš nejakého vojaka a dáš mu príkaz, on ho vykoná. V prípade Gitu budeme oslovovať vojaka s menom `git` a teraz
mu budeme dávať príkaz `init`.

## Vytvorenie repozitára

1. Otvor terminál (alebo Git Bash na Windows) a presuň sa do priečinka, v ktorom chceš repozitár vytvoriť:

```bash
cd cesta/k/mojmu-projektu
```

> **Note:** Príkaz `cd` znamená "Change Directory" a umožňuje nám presunúť sa medzi priečinkami. Aktuálny priečinok sa označuje ako `.` a priečinok o úroveň vyššie ako `..`

2. V požadovanom priečinku spusť príkaz:

```bash
git init
```
Git v tomto priečinku vytvorí skrytý podpriečinok **`.git`**. Práve tam si Git ukladá celú históriu zmien, konfiguráciu
a ďalšie interné dáta — bez neho by priečinok nebol repozitárom.

> **Note:** Git z priečinka odstrániš odstránením priečinka `.git`.

3. Či sa repozitár vytvoril, over príkazom:

```bash
git status
```

Ak príkaz nevypíše chybu typu *"not a git repository"*, ale namiesto toho ukáže stav priečinka (napr. "On branch main, no commits yet"), inicializácia prebehla úspešne.

## Troubleshoot

Po vytvorení repozitára si ako začiatočník vždy skontroluj:
1. Že sa nachádzaš v správnom priečinku - napríklad príkazom `pwd` - Print Working Directory
2. Že sa v tomto priečinku nachádza skrytý priečinok `.git` - napríklad príkazom `ls -a` - List All Files
3. Že `git status` nevypíše chybu *"not a git repository"*
4. Že `git status` nevypíše kopu súborov `../nazov_suboru` to by znamenalo, že sa nachádzaš v nesprávnom priečinku ty, alebo priečinok `.git`

Ak zistíš, že si vytvoril repozitár v nesprávnom priečinku, vymaž v ňom priečinok `.git`

> **Warning:** Študenti často inicializujú repozitár v domovskom priečinku, alebo priečinku o úroveň vyššie ako chceli. Vtedy treba lokalizovať a vymazať nesprávne umiestnený priečinok `.git`

## Zoznam nových príkazov

- `git init` - inicializuje repozitár v aktuálnom priečinku
- `git status` - zistí stav repozitára
- `ls -a` - zoznam všetkých súborov v aktuálnom priečinku, vrátane skrytých
- `cd priecinok` - presuň sa do priečinka `priecinok`
- `cd ..` - vráť sa o priečinok vyššie
- `pwd` - zobraz adresu priečinka, v ktorom sa práve nachádzaš
