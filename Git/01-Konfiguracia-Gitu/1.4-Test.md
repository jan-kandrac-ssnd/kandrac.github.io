<div class="quiz-item active" data-correct="yes">
  <p class="quiz-question">Ak chceme uložiť zmenu v Git-e, Git musí poznať <strong>meno</strong> a <strong>email</strong> používateľa.</p>
  <div class="quiz-actions">
    <button type="button" class="quiz-btn quiz-yes">Áno</button>
    <button type="button" class="quiz-btn quiz-no">Nie</button>
  </div>
  <p class="quiz-comment"><strong>Áno.</strong> Bez <strong>mena</strong> a <strong>emailu</strong> nie je možné zaznamenať žiadnu zmenu v Git-e.</p>
</div>

<div class="quiz-item" data-correct="no" markdown="1">
  <p class="quiz-question">Je toto validný zápis pre nastavenie mena používateľa na <em>Janko</em>?</p>

```bash
git set --global user.name Janko
```

  <div class="quiz-actions">
    <button type="button" class="quiz-btn quiz-yes">Áno</button>
    <button type="button" class="quiz-btn quiz-no">Nie</button>
  </div>
  <p class="quiz-comment"><strong>Nie.</strong> Príkaz <code>git set</code> neexistuje. Používame <code>git config</code>.</p>
</div>

<div class="quiz-item" data-correct="no" markdown="1">
  <p class="quiz-question">Je toto validný zápis pre nastavenie mena používateľa na <em>Janko Hrasko</em>?</p>

```bash
git config --global user.name Janko Hrasko
```

  <div class="quiz-actions">
    <button type="button" class="quiz-btn quiz-yes">Áno</button>
    <button type="button" class="quiz-btn quiz-no">Nie</button>
  </div>
  <p class="quiz-comment"><strong>Nie.</strong> Ak meno obsahuje medzeru, musíme ho vložiť do dvojitých úvodzoviek (inak Git vyhodnotí <em>Hrasko</em> ako ďalší argument).</p>
</div>

<div class="quiz-item" data-correct="yes" markdown="1">
  <p class="quiz-question">Je toto validný zápis pre nastavenie mena používateľa na <em>Janko Hrasko</em>?</p>

```bash
git config --global user.name "Janko Hrasko"
```

  <div class="quiz-actions">
    <button type="button" class="quiz-btn quiz-yes">Áno</button>
    <button type="button" class="quiz-btn quiz-no">Nie</button>
  </div>
  <p class="quiz-comment"><strong>Áno.</strong> Je použitý správny príkaz (<code>git config</code>), správny atribút (<code>user.name</code>) a správna hodnota (<code>"Janko Hrasko"</code>).</p>
</div>

<div class="quiz-item" data-correct="yes" markdown="1">
  <p class="quiz-question">Je toto validný zápis pre nastavenie emailu používateľa na <em>janko@hrasko.sk</em>?</p>

```bash
git config --global user.email janko@hrasko.sk
```

  <div class="quiz-actions">
    <button type="button" class="quiz-btn quiz-yes">Áno</button>
    <button type="button" class="quiz-btn quiz-no">Nie</button>
  </div>
  <p class="quiz-comment"><strong>Áno.</strong> Keďže email neobsahuje medzeru, nemusíme (ale môžeme) ho písať bez úvodzoviek.</p>
</div>

<div class="quiz-item" data-correct="yes" markdown="1">
  <p class="quiz-question">Ak v repozitári zavolám tieto príkazy, vypíše príkaz <code>git config user.name</code> meno <em>Peter Hrasko</em>?</p>

```bash
git config --global user.name "Janko Hrasko"
git config --local user.name "Peter Hrasko"
git config user.name
```

  <div class="quiz-actions">
    <button type="button" class="quiz-btn quiz-yes">Áno</button>
    <button type="button" class="quiz-btn quiz-no">Nie</button>
  </div>
  <p class="quiz-comment"><strong>Áno.</strong> Lokálna konfigurácia repozitára má prednosť pred globálnou konfiguráciou Git-u.</p>
</div>

<div class="quiz-item" data-correct="no" markdown="1">
  <p class="quiz-question">Ak mimo repozitára zavolám tieto príkazy, vypíše príkaz <code>git config user.name</code> meno <em>Peter Hrasko</em>?</p>

```bash
git config --global user.name "Janko Hrasko"
git config --local user.name "Peter Hrasko"
git config user.name
```

  <div class="quiz-actions">
    <button type="button" class="quiz-btn quiz-yes">Áno</button>
    <button type="button" class="quiz-btn quiz-no">Nie</button>
  </div>
  <p class="quiz-comment"><strong>Nie.</strong> Nemôžem nastaviť lokálnu konfiguráciu mimo repozitára, príkaz <code>git config --local</code> sa ukončí chybou.</p>
</div>
