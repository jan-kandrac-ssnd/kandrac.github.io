# 2.2 Git Status

Videli sme, že súbor môže byť **untracked**, **staged**, **committed** alebo **modified**. Otázka je - ako zistíme,
v akom stave sa práve nachádzajú súbory v našom repozitári? Na to slúži príkaz `git status`.

```bash
git status
```

Tento príkaz nič nemení, iba nám **vypíše aktuálny stav** repozitára - ktoré súbory sú untracked, ktoré staged
a ktoré modified (súbory, ktoré sú len committed a odvtedy sa nezmenili, sa vo výpise vôbec nezobrazujú, keďže sa s nimi
"nič nedeje").

## Príklad výpisu

Povedzme, že sme vytvorili nový súbor `main.cpp` a zároveň upravili už predtým committnutý súbor `README.md`. Výpis
`git status` by mohol vyzerať takto:

```text
On branch main
Changes not staged for commit:
  (use "git add <file>..." to update what will be committed)
        modified:   README.md

Untracked files:
  (use "git add <file>..." to include in what will be committed)
        main.cpp
```

Z výpisu vieme prečítať:

1. Na akej **branchi** (vetve) sa aktuálne nachádzame - `main`
2. Ktoré súbory sú **modified** - `README.md`
3. Ktoré súbory sú **untracked** - `main.cpp`

> **Note:** Git nám priamo vo výpise aj napovie, aký príkaz máme použiť, ak chceme súbor presunúť do stavu **staged**
> (`git add <file>`).

Ak by sme teraz spustili `git add main.cpp README.md`, oba súbory by sa presunuli do sekcie **"Changes to be committed"**
a `git status` by nám to potvrdil:

```text
On branch main
Changes to be committed:
  (use "git restore --staged <file>..." to unstage)
        modified:   README.md
        new file:   Main.kt
```

## Skrátený výpis - `git status -s`

Ak ti klasický výpis príde príliš rozvláčny, existuje aj skrátená (skratka **-s** ako *short*) verzia:

```bash
git status -s
```

Výstup je oveľa kompaktnejší - každý súbor je na jednom riadku, s dvojicou znakov na začiatku:

```text
 M README.md
?? Main.kt
```

Najčastejšie znaky, ktoré uvidíš:

- **`??`** - súbor je **untracked**
- **`A`** - súbor je novo pridaný do **staging area**
- **`M`** na prvej pozícii - súbor je staged a zároveň modified
- **`M`** na druhej pozícii - súbor je modified, ale ešte nie staged

> **Tip:** `git status` je príkaz, ktorý budeš (obzvlášť na začiatku) používať neustále - pokojne aj po každom
> jednotlivom príkaze, aby si mal prehľad o tom, čo sa v repozitári deje.
