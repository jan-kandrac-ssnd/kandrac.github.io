# 4.1 Git Log

`git status` nám ozrejmil, v akom stave sa nachádzajú naše, ešte neuložené, zmeny. Našich kolegov ale obvykle nebude
trápiť, čo máme práve rozpracované. Ich bude skôr zaujímať, čo máme dokončené. Dokončenú - tzn. **committed** - prácu si
vieme pozrieť pomocou príkazu `git log`.

Rovno uvádzam verziu so všetkými prepináčikmi, ktoré budeme používať (tie môžeme písať v ľubovoľnom poradí, alebo ich
vynechať):

```bash
git log -5 --oneline --graph --all
```

## Príklady

1. `git log` - zobrazí všetky commitované verzie aj so všetkými informáciami o nich - autor, dátum, správa, …
2. `git log -5` - zobrazí len posledných 5 commitovaných verzií (namiesto 5 môžeš použiť akékoľvek iné číslo)
3. `git log --oneline` - zobrazí jednoriadkové záznamy commitovaných verzií. Vidíme v ňom len skrátený commit hash a správu.
4. `git log --graph` - zobrazí grafickú reprezentáciu commitových verzií - to využijeme, až keď budeme pracovať s viacerými vetvami
5. `git log --all` - zobrazí všetky commitované verzie, aj tie, ktoré nie sú na aktuálnej vetve - to využijeme, až keď budeme pracovať s viacerými vetvami

Okrem týchto prepináčikov existujú aj pekné možnosti formátovania. To je ale ďaleko bonusový materiál a pre ovládanie
gitu nie je potrebný.
