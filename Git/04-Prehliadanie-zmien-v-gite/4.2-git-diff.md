# 4.2 Git Diff a Git Show

`git diff` je príkaz, ktorý zobrazí, čo sa zmenilo medzi dvoma verziami (commitmi) repozitára.

## Príklady

1. Zobraz zmeny v súboroch medzi posledným commitom a **modified** súbormi:

```bash
git diff
```

2. Zobraz zmeny v súboroch medzi dvoma konkrétnymi commitmi (obvykle po sebe nasledujúcimi):

```bash
git diff aebabf5 4d66c25
```

3. Zobraz zmeny v súboroch medzi aktuálnym commitom a definovaným commitom:

```bash
git diff aebabf5
```

## `git show`

Kým `git diff` porovnáva dve ľubovoľné verzie repozitára, `git show` sa pozerá na **jeden konkrétny commit**.
Zobrazí jeho metadáta (autora, dátum, commit message) a zároveň zmeny, ktoré tento commit priniesol - teda diff
oproti jeho priamemu rodičovi.

```bash
git show aebabf5
```

Ak commit nešpecifikuješ vôbec, `git show` zobrazí posledný commit (`HEAD`):

```bash
git show
```

> **Tip:** `git show` vieš skombinovať aj s relatívnymi odkazmi na commit (napríklad `HEAD~1` alebo `HEAD^`), ktorým
> sa budeme venovať v kapitole o navigácii v Git-e.
