# 5.2 Git Branch

Vďaka vetvám vieme mať v jednom repozitári paralelne rozpracovaných viacero vecí (napr. novú funkcionalitu, opravu bugu,
experiment), bez toho, aby sme si navzájom "rozbíjali" prácu.

Zoznam všetkých existujúcich vetiev v repozitári získame príkazom:

```bash
git branch
```

Výpis môže vyzerať napríklad takto:

```text
* main
```

Hviezdička (`*`) pred názvom vetvy znamená, že práve na tejto vetve sa aktuálne nachádzame.

## Vytvorenie novej vetvy

Novú vetvu vytvoríme príkazom:

```bash
git branch nazov-vetvy
```

Ak si teraz znova vypíšeme zoznam vetiev, uvidíme obe:

```text
* main
  nazov-vetvy
```

> **Note:** Všimni si, že hviezdička je **stále** pri vetve `main`. `git branch nazov-vetvy` novú vetvu iba
> **vytvorí**, ale automaticky nás na ňu nepresunie - stále pracujeme na pôvodnej vetve.

Na to, aby sme sa na novovytvorenú vetvu reálne presunuli (a začali na nej pracovať), budeme potrebovať iný príkaz -
tomu sa budeme venovať v nasledujúcej lekcii.
