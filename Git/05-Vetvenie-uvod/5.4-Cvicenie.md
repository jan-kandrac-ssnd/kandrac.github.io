# 5.4 Cvičenie - Rybičky 2

Vo funkcii `printAquarium` sa generuje rám akvária. Vytvor 2 vetvy na ktorých vyskúšaš 2 rôzne rámy. Napríklad nahraď:

```text
+--------------------------------------------------------------------------------+
|                                                                                |
|                                                                                |
|                                                                                |
|                                                                                |
|                                                                                |
|                                                                                |
|                                                                                |
|                                                                                |
|                                                                                |
|                                                                                |
|                                                                                |
|                                                                                |
|                                                                                |
|                                                                                |
|                                                                                |
+--------------------------------------------------------------------------------+
```

takýmto akváriom na jednej vetve:

```text
#================================================================================#
$                                                                                $
$                                                                                $
$                                                                                $
$                                                                                $
$                                                                                $
$                                                                                $
$                                                                                $
$                                                                                $
$                                                                                $
$                                                                                $
$                                                                                $
$                                                                                $
$                                                                                $
$                                                                                $
$                                                                                $
#================================================================================#
```

a takýmto na druhej:

```text
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
~                                                                                ~
~                                                                                ~
~                                                                                ~
~                                                                                ~
~                                                                                ~
~                                                                                ~
~                                                                                ~
~                                                                                ~
~                                                                                ~
~                                                                                ~
~                                                                                ~
~                                                                                ~
~                                                                                ~
~                                                                                ~
~                                                                                ~
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
```

Stopni si čas, ako rýchlo ti bude trvať spustiť obe varianty. Prepínanie medzi vetvami bude rýchlejšie, ako manuálna
úprava znakov.
