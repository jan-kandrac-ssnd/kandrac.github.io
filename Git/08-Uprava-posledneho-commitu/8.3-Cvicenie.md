# 8.3 Cvičenie - Úprava posledného commitu

Vrátime sa opäť k ASCII akváriu. Tentokrát som pridal nejaké tie branche a na oboch budeme robiť zmeny pomocou
`git commit --amend`.

1. Stiahni si repozitár [ascii_aquarium.zip](ascii_aquarium.zip) a rozbaľ ho.
2. Na poslednom commite na branch main uprav kraba tak, aby mal aj oči a odstráň úvodné medzery:

Originál:
```text
  /_\    /_\
  \ /____\ /
  /\______/\
    /\  /\
```

Nový:
```text
/_\    /_\
\ /O__O\ /
/\______/\
  /\  /\
```

3. Na branchi `interactive-menu` je v hlavnom menu typo. Nájdi a oprav ho.
4. Na branchi `interactive-menu` zmeň aj text commit message na `Add ASCII menu`.
