# 9.2 Interaktívny Rebase - Reword

`reword` (skratka `r`) funguje podobne ako `git commit --amend -m "..."`, ale vieš ho použiť na **ktorýkoľvek**
commit v zozname, nielen na ten posledný.

## Použitie

V zozname interaktívneho rebase zmeň `pick` na `reword` (alebo len `r`) pri commite, ktorého správu chceš zmeniť:

```text
pick 4d66c25 Pridanie tlačidla
r    aebabf5 oprava layotu
pick 915e2da Refaktoring
pick 89f779a Pridanie testov
```

Po uložení a zatvorení tohto zoznamu ti Git otvorí **ďalší** editor - tentokrát len s pôvodnou správou commitu
`aebabf5`, ktorú môžeš upraviť:

```text
oprava layotu

# Please enter the commit message for your changes. Lines starting
# with '#' will be ignored...
```

Uprav text (napríklad na `Oprava layoutu`), ulož a zatvor editor. Git dokončí zvyšok rebase - všetky nasledujúce
commity (`915e2da`, `89f779a`) sa automaticky prepíšu s novými hashmi, keďže ich "rodič" sa zmenil.

> **Dôležité:** Aj keď meníš len jeden commit v strede histórie, **všetky commity za ním** dostanú nový hash.
> Obsah súborov sa nezmení - zmení sa iba identita (hash) commitov.

> **Tip:** Ak potrebuješ prepísať viacero správ naraz, jednoducho označ `reword` pri viacerých riadkoch - Git ťa
> postupne vyzve na úpravu každej z nich, jednu po druhej.
