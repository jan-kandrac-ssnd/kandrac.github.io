# 9.3 Interaktívny Rebase - Drop

Príkaz `drop` (skratka `d`) commit z histórie **úplne odstráni**, akoby nikdy nevznikol.

## Použitie

```text
pick 4d66c25 Pridanie tlačidla
pick aebabf5 Oprava layoutu
drop 915e2da Experimentálny debug log
pick 89f779a Pridanie testov
```

Po uložení zoznamu Git commit `915e2da` preskočí a zvyšné commity naň jednoducho nenadviažu - akoby nikdy
neexistoval.

> **Note:** Rovnaký efekt dosiahneš aj tak, že príslušný riadok zo zoznamu úplne **vymažeš** namiesto zmeny na
> `drop` - obe možnosti sú ekvivalentné.

> **Dôležité:** `drop` odstráni **celý** commit vrátane všetkých zmien, ktoré obsahoval. Ak commit menil viacero
> súborov a chceš zahodiť len časť z nich, `drop` nie je správna voľba - na to použi `edit`, ktorému sa venujeme
> v nasledujúcej kapitole.

## Kedy sa `drop` hodí?

1. Commitol si dočasný debug výpis, ktorý nechceš mať v histórii
2. Vyskúšal si experimentálnu zmenu, ktorá sa nakoniec neosvedčila
3. Commit obsahuje niečo, čo si tam pridal omylom

> **Tip:** Pred zahodením commitu si vždy over `git show <commit>`, aby si presne vedel, čo commit obsahoval -
> vyhneš sa tak neúmyselnej strate práce.
