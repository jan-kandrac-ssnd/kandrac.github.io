# 13.3 Nahratie SSH Kľúčov na GitHub

Svoj verejný kľúč si v prechádzajúcej téme vygeneroval do súboru `~/.ssh/id_ed25519.pub`. Obsah tohto súboru skopíruj,
budeme ho potrebovať. Musíme ho nahrať na GitHub.

[13.3-Nahratie-SSH-klucov-na-GitHub.md](13.3-Nahratie-SSH-klucov-na-GitHub.md)

## Pridanie kľúča na GitHub

Kľúč vieš vytvoriť na tejto stránke `SSH and GPG keys` v nastaveniach tvojho GitHub účtu: https://github.com/settings/keys

1. Na GitHub-e klikni na svoj profilový obrázok vpravo hore a vyber **Settings**
2. V ľavom menu nájdi **SSH and GPG keys**
3. Klikni na **New SSH key**
4. Do poľa **Title** napíš, o aké zariadenie ide (napríklad "Môj notebook"), aby si sa vedel neskôr v zozname
   zorientovať
5. Do poľa **Key** vlož obsah, ktorý si skopíroval v predchádzajúcom kroku
6. Potvrď tlačidlom **Add SSH key**

## Overenie spojenia

Funkčnosť si over priamo v termináli:

```bash
ssh -T git@github.com
```

Pri prvom spustení sa ťa terminál opýta, či dôveruješ GitHub-ovému serveru - potvrď **yes**. Ak je všetko správne
nastavené, uvidíš správu podobnú tejto:

```text
Hi tvoje-meno! You've successfully authenticated, but GitHub does not provide shell access.
```

Táto správa je v poriadku, aj keď spomína, že sa "nedá pripojiť cez shell" - to je očakávané, GitHub len overil
tvoju identitu.

## Windows troubleshooting

Pri Windows môžeš pri spustení príkazu `ssh -T git@github.com` dostať chybu. Môžeš mať jeden z nasledujúcich problémov:

### SSH kľúč nebol Pridaný do SSH agenta

SSH kľúč si vytvoril príkazom `ssh-keygen`. Je možné, že nebol pridaný do SSH agenta. Návod na riešenie nájdeš v
[oficiálnej dokumentácii](https://docs.github.com/en/authentication/connecting-to-github-with-ssh/generating-a-new-ssh-key-and-adding-it-to-the-ssh-agent?platform=windows#adding-your-ssh-key-to-the-ssh-agent).

1. Otvor Windowsový PowerShell ako administrátor a spusti príkaz:
```bash
Get-Service -Name ssh-agent | Set-Service -StartupType Manual
Start-Service ssh-agent
```
2. Pridaj kľúč do SSH agenta - to už nemusíš urobiť ako administrátor:
```bash
ssh-add c:/Users/YOU/.ssh/id_ed25519
```

### Konflitní SSH agenti

Aj GitBash aj Windows môžu mať svojho vlastného SSH agenta. Musíme Gitu odkázať, ktorého SSH agenta má použiť volaním
príkazu:

```bash
git config --global core.sshCommand "C:/Windows/System32/OpenSSH/ssh.exe"
```
