# 13.4 Cvičenia

## Cvičenie 1 - Môj prvý privátny repozitár - clone

Na GitHube:
1. zvoľ vytvorenie nového repozitára
2. označ ho ako **privátny**
3. zaškrtni **Initialize this repository with a README**

Takto vytvorený repozitár už obsahuje jeden commit, preto ho je možné rovno naklonovať pomocou príkazu `git clone`.

## Cvičenie 2 - Inicializácia repozitára z lokálneho počítača

Lokálne vytvor nový git repozitár s 2-3 commitmi

Na GitHube:
1. zvoľ vytvorenie nového repozitára
2. označ ho ako **privátny**
3. **nezaškrtávaj Initialize this repository with a README** !!!
4. podľa návodu na stránke nahraj svoj lokálny repozitár na GitHub

## Cvičenie 3 - Vymazanie repozitára na GitHub-e

Nájdi v nastaveniach repozitára možnosť **Delete this repository** a vymaž ktorýkoľvek cvičný repozitár.
