# Git remote

Viac krát mi ušlo slovíčko `REMOTE` alebo `origin` a možno som ich medzi sebou aj zamieňal.

Keď sme si ukazovali `GitHub` hovoril som o ňom len ako o jednej z viacerých alternatív - popri GitLabe, BitBuckete alebo iných.
Z pohľadu lokálneho repozitára je úplne jedno, kto službu hostuje. Lokálny repozitár všetky vzdialené repozitáre (ktoré
hostujeme na niektorej z týchto služieb) označuje slovíčkom **REMOTE**.

> Zhrnutie: Vzdialený repozitár označujeme slovom `REMOTE` bez ohľadu na to, kto nám túto službu poskytuje

Slovo `origin` je len označenie/pomenovanie pre `remote` a obvykle je to názov pre predvolený `remote`. Ak si si
napríklad naklonoval repozitár z GitHub-u, tak si **zoznam remote-ov** aj s ich názvami vieš vypísať pomocou príkazu

```shell
git remote -v
```

A na výstupe uvidíš výstup podobný tomuto:

```shell
origin	git@school.github.com:jan-kandrac-ssnd/kandrac.github.io.git (fetch)
origin	git@school.github.com:jan-kandrac-ssnd/kandrac.github.io.git (push)
```

To znamená, že `remote` s názvom `origin` má url pre fetchovanie (sťahovanie dát) aj pre pushovanie (nahrávanie dát)
nastavenú na hodnotu `git@school.github.com...`.

Teda ak zavolám `git push`, `git pull`, `git fetch` (tento príkaz ešte nepoznáte), použije sa url pre `remote` s názvom
`origin`. Ak by som mal `remote`-ov viac, tak by som pri týchto operáciách mal použiť aj označenie daného `remote`.

```shell
git push origin
git pull origin
git fetch origin
```

## Príkaz `git remote`

Ak budete chcieť upravovať čokoľvek vrámci `remote`-ov použijete príkaz `git remote`. Rýchly prehľad alternatív
uvádzam v týchto ukážkach:

```shell
git remote -v                                 # vypise zoznam remoteov
git remote add novy_remote git@user.github... # vytvori novy remote s nazvom novy_remote s danou url
git remote set-url origin git@user.github...  # nastavi url pre existujuci remote s nazvom origin na danu url
git remote rename old new                     # premenuje remote s nazvom old na nazov new
git remote remove origin                      # vymaze referenciu na remote s nazvom origin
```
