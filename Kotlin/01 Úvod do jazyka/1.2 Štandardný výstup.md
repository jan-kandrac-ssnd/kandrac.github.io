## Štandardný výstup

Ak chceš čokoľvek vypísať na štandardný výstup použi jednu z funkcií `print` alebo `println`:

```kt
fun main() {
    println("Hello World") // ; v kotline nepouzivame
    println("Ahoj Svet")   // vypise text a znak konca riadku
    println(123)           // alebo cele cislo
    println(-1.25)         // alebo desatinne cislo
    println()              // alebo len prazdny riadok
    
    print("Bez new line")  // alebo text bez \n
    print("S new line\n")  // alebo manualne zadaj \n
}
```

## Úlohy

### 1. Basics

Na štandardný výstup vypíš, ako vyzerá hello world v jazyku C++, teda vypíš tento text:

```cpp
#include <iostream>

using namespace std;

int main() {
    cout << "Hello World" << endl;
}
```
