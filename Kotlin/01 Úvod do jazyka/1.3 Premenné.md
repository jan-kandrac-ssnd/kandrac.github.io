Pre deklarovanie a inicializáciu premennej v Kotline použijeme
1. slovíčko `var` alebo `val` a za ním
2. názov premennej
3. dvojbodku
4. typ premennej
5. rovná sa
6. hodnotu

Napríklad:
```kt
fun main() {
    var premenna: Int = 10
    val inaPremenna: Int = 20
}
```

Kotlin je dosť striktný čo sa týka neinicializovaných premenných, preto odporúčam každú premennú inicializovať. Ak premennú neinicializuješ pred jej prvým volaním, projekt ani neskompiluješ.

Premenná s označením `var` vie byť neskôr zmenená, premenná s označením `val` nie. Vždy keď je to možné používame `val`. Ak použijeme `var` väčšinou sa dá náš program zjednodušiť. Slovíčko `var` takmer nepoužívame.

> `var` (variable) je premenná a jej hodnotu vieme kedykoľvek zmeniť
> `val` (value) je hodnota a jej hodnotu nevieme po inicializácii zmeniť

### 1.4.1 Type inference
Keďže je typ premennej veľmi ľahko predvídateľný, v Kotline väčšinou nemusíme typ premennej vôbec zapisovať, takže aj toto je valídny a oveľa častejšie používaný zápis:

```kt
fun main() {
    var premenna = 10
    val inaPremenna = 20
}
```
