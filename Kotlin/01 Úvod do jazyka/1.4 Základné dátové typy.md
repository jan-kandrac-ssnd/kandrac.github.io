V Kotline poznáme klasické dátové typy. Všetky ale zapisujeme veľkým začiatočným písmenom.

>Malé začiatočné písmená používame len pre názvy premenných a funkcií

Toto sú základné typy, ktoré potrebujeme poznať:
1. `Boolean` - `true` / `false`
2. `Char` - `'a'`, `'b'`, `'\n'`
3. `Int` - `1`, `0xFF`, `-10`
4. `Long` - `1L`, `0xFFL`
5. `Float` - `1.0F`, `1.0f`
6. `Double` - `1.0`
7. `String` - `"hello"`

### 1.5.1 Typ Unit
Ďalším špeciálnym typom je `Unit` ten používame ako návratovú hodnotu funkcie, ktorá nevracia nič. Funkciu `main` vieme vďaka `Unit` zapísať nasledovne:
```kt
fun main(): Unit {
    // ...
}
```
Obvykle slovíčko `Unit` nezapisujeme, ale je dobré o ňom vedieť. Podobá sa na `void` v C++ (ale nie je ekvivalentný).
