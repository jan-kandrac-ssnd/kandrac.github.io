## Základné dátové typy

V Kotline poznáme klasické dátové typy. Všetky ale zapisujeme veľkým začiatočným písmenom.

>Malé začiatočné písmená používame len pre názvy premenných a funkcií

Toto sú základné typy, ktoré potrebujeme poznať:
1. `Boolean` - `true` / `false`
2. `Char` - `'a'`, `'b'`, `'\n'`
3. `Int` - `1`, `0xFF`, `-10`
4. `Long` - `1L`, `0xFFL`
5. `Float` - `1.0F`, `1.0f`
6. `Double` - `1.0`
7. `String` - `"hello"`

## Typ Unit
Ďalším špeciálnym typom je `Unit` ten používame ako návratovú hodnotu funkcie, ktorá nevracia nič. Funkciu `main` vieme vďaka `Unit` zapísať nasledovne:
```kt
fun main(): Unit {
    // ...
}
```
Obvykle slovíčko `Unit` nezapisujeme, ale je dobré o ňom vedieť. Podobá sa na `void` v C++ (ale nie je ekvivalentný).

## Úlohy

### 1. Nemenné premenné

Vytvor dve hodnoty (`val`) typu `Int` a na štandardný výstup vypíš na samostatných riadkoch výsledky operácií `+-*/`. Pri výpise používaj priamo tieto premenné, nie hardcoded výstup.

### 2. String + String

Skús vytvoriť 2 premenné typu String a sčitať ich. Ak sa dá dostať k výsledku, vypíš ho na štandardný výstup.

### 3. String + Int

Skús sčítať `String` + `Int` alebo `Int` + `String` a výstup vypísať na štandardný výstup. Ak to nepôjde skús použiť String interpolation.
