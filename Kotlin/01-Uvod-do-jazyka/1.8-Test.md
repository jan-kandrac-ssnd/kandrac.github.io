<div class="quiz-item active" data-correct="yes" markdown="1">
  <p class="quiz-question">Je nasledovný kód platný?</p>

```kotlin
val meno: String = readln()
println("Ahoj, $meno!")
```

  <div class="quiz-actions">
    <button type="button" class="quiz-btn quiz-yes">Áno</button>
    <button type="button" class="quiz-btn quiz-no">Nie</button>
  </div>
  <p class="quiz-comment"><strong>Áno.</strong> Funkcia <code>readln()</code> vždy vracia hodnotu typu <code>String</code>, takže priradenie do premennej explicitne typu <code>String</code> je v poriadku.</p>
</div>

<div class="quiz-item" data-correct="yes">
  <p class="quiz-question">Objekt <code>System.`in`</code> reprezentuje štandardný vstup, na ktorý sa vieme napojiť napríklad pomocou <code>Scanner(System.`in`)</code>.</p>
  <div class="quiz-actions">
    <button type="button" class="quiz-btn quiz-yes">Áno</button>
    <button type="button" class="quiz-btn quiz-no">Nie</button>
  </div>
  <p class="quiz-comment"><strong>Áno.</strong> <code>in</code> je v Kotline vyhradené kľúčové slovo, preto ho pri prístupe k <code>System.in</code> obaľujeme spätnými apostrofmi: <code>System.`in`</code>.</p>
</div>

<div class="quiz-item" data-correct="yes" markdown="1">
  <p class="quiz-question">Je nasledovný kód platný?</p>

```kotlin
import java.util.Scanner

fun main() {
    val scanner = Scanner(System.`in`)
    val cislo = scanner.nextInt()
    println(cislo)
}
```

  <div class="quiz-actions">
    <button type="button" class="quiz-btn quiz-yes">Áno</button>
    <button type="button" class="quiz-btn quiz-no">Nie</button>
  </div>
  <p class="quiz-comment"><strong>Áno.</strong> <code>Scanner</code> importujeme z balíka <code>java.util</code> a funkcia <code>nextInt()</code> načíta a rovno pretypuje ďalší token vstupu na <code>Int</code>.</p>
</div>

<div class="quiz-item" data-correct="yes">
  <p class="quiz-question">Funkcie <code>next...</code> (napr. <code>nextInt</code>, <code>nextDouble</code>) v triede <code>Scanner</code> pred načítaním automaticky preskočia biele znaky.</p>
  <div class="quiz-actions">
    <button type="button" class="quiz-btn quiz-yes">Áno</button>
    <button type="button" class="quiz-btn quiz-no">Nie</button>
  </div>
  <p class="quiz-comment"><strong>Áno.</strong> Funkcie <code>next...</code> preskakujú biele znaky a načítajú ďalší token, na rozdiel od <code>nextLine</code>.</p>
</div>

<div class="quiz-item" data-correct="no" markdown="1">
  <p class="quiz-question">Po zadaní čísla <code>5</code> a stlačení Enter, načíta premenná <code>riadok</code> v tomto kóde neprázdny reťazec?</p>

```kotlin
val scanner = Scanner(System.`in`)
val cislo = scanner.nextInt()
val riadok = scanner.nextLine()
println("Riadok: '$riadok'")
```

  <div class="quiz-actions">
    <button type="button" class="quiz-btn quiz-yes">Áno</button>
    <button type="button" class="quiz-btn quiz-no">Nie</button>
  </div>
  <p class="quiz-comment"><strong>Nie.</strong> <code>nextInt()</code> nedočíta znak konca riadku za číslom, takže nasledujúce <code>nextLine()</code> prečíta iba zvyšok aktuálneho (už takmer prázdneho) riadku - výsledkom je prázdny reťazec <code>''</code>.</p>
</div>

<div class="quiz-item" data-correct="no">
  <p class="quiz-question">Je bezpečné v jednom programe kombinovať <code>readln()</code> aj <code>Scanner</code> súčasne na čítanie zo štandardného vstupu.</p>
  <div class="quiz-actions">
    <button type="button" class="quiz-btn quiz-yes">Áno</button>
    <button type="button" class="quiz-btn quiz-no">Nie</button>
  </div>
  <p class="quiz-comment"><strong>Nie.</strong> <code>readln()</code> a <code>Scanner</code> používajú odlišné mechanizmy na čítanie vstupu a ich kombinovanie môže spôsobiť neočakávané správanie (napr. stratu alebo duplicitné čítanie dát).</p>
</div>

<script>
  (function () {
    const questionsWrap = document.getElementById('quiz-questions');
    const summaryEl = document.getElementById('quiz-summary');
    const scoreEl = document.getElementById('quiz-score');
    const restartBtn = document.getElementById('quiz-restart');
    const items = Array.from(document.querySelectorAll('#quiz-container .quiz-item'));
    const progress = document.getElementById('quiz-progress');
    const prevBtn = document.getElementById('quiz-prev');
    const nextBtn = document.getElementById('quiz-next');
    let current = 0;

    function updateNav() {
      const isLast = current === items.length - 1;
      prevBtn.disabled = current === 0;
      nextBtn.disabled = !items[current].classList.contains('answered');
      nextBtn.textContent = isLast ? 'Vyhodnotiť →' : 'Ďalšia →';
    }

    function showItem(index) {
      items.forEach((item, i) => item.classList.toggle('active', i === index));
      progress.textContent = 'Otázka ' + (index + 1) + ' / ' + items.length;
      updateNav();
    }

    function answerItem(item, btn, correct) {
      if (item.classList.contains('answered')) return;
      item.classList.add('answered');

      const chosen = btn.classList.contains('quiz-yes') ? 'yes' : 'no';
      const isCorrect = chosen === correct;
      item.dataset.result = isCorrect ? 'correct' : 'incorrect';
      btn.classList.add(isCorrect ? 'correct' : 'incorrect');

      if (!isCorrect) {
        const correctBtn = item.querySelector(correct === 'yes' ? '.quiz-yes' : '.quiz-no');
        correctBtn.classList.add('correct');
      }

      item.querySelectorAll('.quiz-btn').forEach((b) => { b.disabled = true; });
      item.querySelector('.quiz-comment').classList.add('visible');
      updateNav();
    }

    items.forEach((item) => {
      const correct = item.dataset.correct;
      item.querySelectorAll('.quiz-btn').forEach((btn) => {
        btn.addEventListener('click', () => answerItem(item, btn, correct));
      });
    });

    function showSummary() {
      const score = items.filter((item) => item.dataset.result === 'correct').length;
      scoreEl.textContent = score + ' / ' + items.length;
      questionsWrap.style.display = 'none';
      summaryEl.classList.add('visible');
    }

    function resetQuiz() {
      items.forEach((item) => {
        item.classList.remove('answered');
        delete item.dataset.result;
        item.querySelectorAll('.quiz-btn').forEach((b) => {
          b.disabled = false;
          b.classList.remove('correct', 'incorrect');
        });
        item.querySelector('.quiz-comment').classList.remove('visible');
      });
      summaryEl.classList.remove('visible');
      questionsWrap.style.display = '';
      current = 0;
      showItem(current);
    }

    prevBtn.addEventListener('click', () => {
      if (current > 0) {
        current -= 1;
        showItem(current);
      }
    });

    nextBtn.addEventListener('click', () => {
      if (current === items.length - 1) {
        showSummary();
        return;
      }
      current += 1;
      showItem(current);
    });

    restartBtn.addEventListener('click', resetQuiz);

    showItem(current);
  })();
</script>
