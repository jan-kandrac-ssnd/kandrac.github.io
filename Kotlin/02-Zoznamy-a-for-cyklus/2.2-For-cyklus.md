## Cyklus for

Klasické použitie for cyklu je prechod intervalom hodnôt (`Range`) alebo rovno zoznamom (`List`) Preto sa Kotlin nebabre s podmienkovaním ale rovno nastavuje iterátoru (`i`) hodnotu podľa potreby.

Iterátor `i` nadobúda hodnoty v (`in`) nejakom intervale intervale. `for` cyklus preto vieme nad intervalom zapísať nasledovne:
```kotlin
fun main() {
    for (i in 0..5)  print(i) // 012345
    for (i in 0..<5) print(i) // 01234
}
```

> 0..5 vytvára premennú typu `Range`, ktorá je istou formou `List`-u

Alebo teda iterátor i nadobúda hodnoty zo zoznamu:
```kotlin
fun main() {
    for (i in listOf("Jan", "Fero", "Mark")) {
        println(i)    // JanFeroMark
    }
}
```

Existujú aj iné zápisy, ale tie sa používajú zriedka. Pozri si kľúčové slovíčka `downTo` alebo `step`
