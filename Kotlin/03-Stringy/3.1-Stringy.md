# 3.1 Typ String a jeho funkcie

Typ String je jeden zo základných typov, no obsahuje obrovské množstvo funkcií pre manipuláciu. Ukážme si teda niektoré základné funkcie nad typom String:

```kotlin
fun main() {
    "jablko,hruska,banan".split(",")         // ["jablko", "hruska", "banan"]
    "jablko,hruska,banan".contains("hruska") // true
    "jablko,hruska".startsWith("jablko")     // true
    "jalko,hruska".endsWith("hruska")        // true
    "Peter".uppercase()                      // "PETER"
    "Peter".lowercase()                      // "peter"
    "I <3 Java".replace("Java", "Kotlin")    // "I <3 Kotlin"
    "Textik".length                          // 6
    "Textik".substring(2, 4)                 // "xt"
    "  ahoj ".trim()                         // "ahoj"
}
```

## Úlohy

### 1. Upratovanie mena

Zo štandardného vstupu načítaj meno používateľa. Meno môže obsahovať medzery na začiatku alebo na konci a môže byť napísané ľubovoľnou kombináciou veľkých a malých písmen.

Na výstup vypíš meno bez prebytočných medzier a celé veľkými písmenami.

| Ukážka vstupu   | Ukážka výstupu |
| --------------- | -------------- |
| `  jAn NoVaK  ` | `JAN NOVAK`    |
| `peter `        | `PETER`        |

### 2. E-mail

Na štandardnom vstupe načítaj e-mailovú adresu používateľa. Vypíš používateľské meno pred znakom `@` a doménu za znakom `@`.

| Ukážka vstupu    | Ukážka výstupu        |
| ---------------- | --------------------- |
| `fero@gmail.com` | `fero`<br>`gmail.com` |
| `jana@uniza.sk`  | `jana`<br>`uniza.sk`  |

### 3. Skrytý text

Na vstupe načítaj ľubovoľný text. Program vypíše jeho dĺžku a následne text nahradí všetky výskyty slova `tajne` slovom `***`.

| Ukážka vstupu         | Ukážka výstupu              |
| --------------------- | --------------------------- |
| `Toto je tajne heslo` | `19`<br>`Toto je *** heslo` |
| `tajne tajne tajne`   | `17`<br>`*** *** ***`       |

### 4. Prezývka

Na vstupe načítaj celé meno vo formáte:

```text
Meno Priezvisko
```

Vypíš používateľskú prezývku v tvare:

```text
priezvisko.meno
```

pričom všetky písmená majú byť malé.

| Ukážka vstupu    | Ukážka výstupu   |
| ---------------- | ---------------- |
| `Ján Novák`      | `novák.ján`      |
| `Peter Mrkvička` | `mrkvička.peter` |

### 5. Kontrola hesla

Na vstupe načítaj heslo. Vypíš jeho dĺžku a informáciu, či obsahuje text `123`.

| Ukážka vstupu    | Ukážka výstupu  |
| ---------------- | --------------- |
| `mojeheslo123`   | `12`<br>`true`  |
| `k0mp1exneheslo` | `14`<br>`false` |

### 6. Rozdelenie názvu súboru

Na vstupe načítaj názov súboru vo formáte:

```text
nazov.pripona
```

Vypíš názov súboru a jeho príponu samostatne.

| Ukážka vstupu      | Ukážka výstupu          |
| ------------------ | ----------------------- |
| `fotka.jpg`        | `fotka`<br>`jpg`        |
| `prezentacia.pptx` | `prezentacia`<br>`pptx` |
| `program.kt`       | `program`<br>`kt`       |

### 7. Hľadanie slova

Načítaj vetu a následne slovo, ktoré chce používateľ vo vete nájsť. Vypíš `true`, ak sa slovo vo vete nachádza, inak `false`.

| Ukážka vstupu                      | Ukážka výstupu |
| ---------------------------------- | -------------- |
| `Dnes je krásny deň.`<br>`krásny`  | `true`         |
| `Dnes je krásny deň.`<br>`škaredý` | `false`        |
| `Kotlin je super.`<br>`Java`       | `false`        |

### 8. Generátor používateľského mena

Na vstupe načítaj meno a priezvisko. Program vytvorí používateľské meno v tvare:

```text
prvé 3 písmená mena + prvé 3 písmená priezviska
```

Používateľské meno musí byť napísané malými písmenami.

| Ukážka vstupu     | Ukážka výstupu |
| ----------------- | -------------- |
| `Peter Novak`     | `petnov`       |
| `Jana Mrkvickova` | `janmrk`       |
| `Marek Kral`      | `markra`       |

### 9. Spracovanie zoznamu

Na vstupe načítaj zoznam ovocia oddelený čiarkami. Vypíš každé ovocie na samostatný riadok.

| Ukážka vstupu            | Ukážka výstupu                     |
| ------------------------ | ---------------------------------- |
| `jablko,hruska,banan`    | `jablko`<br>`hruska`<br>`banan`    |
| `pizza,hamburger,hotdog` | `pizza`<br>`hamburger`<br>`hotdog` |
