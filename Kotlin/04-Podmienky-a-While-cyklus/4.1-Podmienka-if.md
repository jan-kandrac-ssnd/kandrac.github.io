# 4.1 Podmienka if

Podmienku `if` poznáme skoro v každom jazyku. Jednou z klasických ukážok je nasledovná:
```kotlin
fun main() {
    val age = readln().toInt()
    if (age < 18) {
        println("Maloletym nepredavam")
        return
    }
}
```

Blok za `if`-om sa vykoná len ak výraz v zátvorke za `if`-om vráti `true`. Pozor, nemusí to byť len porovnávanie, ale čokoľvek, čo vracia `true`/`false`, napríklad `"hello".contains("hell")`.

Typicky poznáme aj `else if` kľúčové slová. V prípade if-else sa spustí ten blok, ktorého podmienka bude splnená ako prvá. Ak nebude splnená žiadna, nespustí sa ani jeden:

```kotlin
fun main() {
    val age = readln().toInt()
    if (age < 18) {
        println("Maloletym nepredavam")
        return
    } else if (age < 21) {
        println("Potrebujem obciansky")
        return
    } else if (age > 85) {
        println("Rizikova skupina")
        return
    }
}
```

Alebo poznáme klasický `else` - ak nebude splnená žiadna podmienka, spustí sa else vetva:

```kotlin
fun main() {
    val age = readln().toInt()
    if (age < 18) {
        println("Maloletym nepredavam")
        return
    } else {
        println("Nech sa paci")
    }
}
```

## Úlohy

### 1. Plnoletosť

Na štandardnom vstupe načítaj vek používateľa. Ak je používateľ plnoletý, vypíš `Plnolety`, inak vypíš `Maloletý`.

| Ukážka vstupu | Ukážka výstupu |
| ------------- | -------------- |
| `20`          | `Plnolety`     |
| `15`          | `Maloletý`     |

### 2. Kladné alebo záporné

Na vstupe načítaj celé číslo. Vypíš `Kladne`, ak je číslo väčšie ako nula, a `Zaporne`, ak je menšie ako nula. Ak je číslo rovné nule, vypíš `Nula`.

| Ukážka vstupu | Ukážka výstupu |
| ------------- | -------------- |
| `42`          | `Kladne`       |
| `-7`          | `Zaporne`      |
| `0`           | `Nula`         |

### 3. Známka

Na vstupe načítaj známku od `1` do `5`. Vypíš slovné hodnotenie:

* `1` → `Vyborne`
* `2` → `Chvalitebne`
* `3` → `Dobre`
* `4` → `Dostatocne`
* `5` → `Nedostatocne`

| Ukážka vstupu | Ukážka výstupu |
| ------------- | -------------- |
| `1`           | `Vyborne`      |
| `3`           | `Dobre`        |
| `5`           | `Nedostatocne` |

### 4. Teplota

Na vstupe načítaj teplotu v stupňoch Celzia. Vypíš:

* `Mrzne`, ak je teplota menšia ako `0`,
* `Chladno`, ak je od `0` do `14`,
* `Prijemne`, ak je od `15` do `24`,
* `Teplo`, ak je `25` alebo viac.

| Ukážka vstupu | Ukážka výstupu |
| ------------- | -------------- |
| `-5`          | `Mrzne`        |
| `12`          | `Chladno`      |
| `21`          | `Prijemne`     |
| `30`          | `Teplo`        |

### 5. Zľava v obchode

Na vstupe načítaj cenu nákupu. Ak je cena aspoň `100 €`, zákazník dostane zľavu `10 %`. Inak zľavu nedostane. Vypíš výslednú cenu po zľave.

| Ukážka vstupu | Ukážka výstupu |
| ------------- | -------------- |
| `50`          | `50.0`         |
| `100`         | `90.0`         |
| `250`         | `225.0`        |

### 6. Najväčšie číslo

Na vstupe načítaj dve celé čísla. Vypíš väčšie z nich. Ak sú rovnaké, vypíš `Rovnake`.

| Ukážka vstupu | Ukážka výstupu |
| ------------- | -------------- |
| `8`<br>`13`   | `13`           |
| `25`<br>`7`   | `25`           |
| `10`<br>`10`  | `Rovnake`      |

### 7. Heslo

Na vstupe načítaj heslo. Ak je heslo presne `kotlin123`, vypíš `Prihlasene`, inak vypíš `Nespravne heslo`.

### 8. Vstupenka

Na vstupe načítaj vek návštevníka. Cena vstupenky je:

* do `6` rokov vrátane: `0 €`,
* od `7` do `17` rokov: `5 €`,
* od `18` do `64` rokov: `10 €`,
* od `65` rokov: `6 €`.

Vypíš cenu vstupenky.

| Ukážka vstupu | Ukážka výstupu |
| ------------- | -------------- |
| `5`           | `0`            |
| `12`          | `5`            |
| `30`          | `10`           |
| `70`          | `6`            |

### 9. Deliteľnosť

### 10. Kalkulačka

Na vstupe načítaj dve čísla a následne znak operácie (`+`, `-`, `*` alebo `/`). Vypíš výsledok danej operácie. Ak používateľ zadá inú operáciu, vypíš `Neznama operacia`.

| Ukážka vstupu      | Ukážka výstupu     |
| ------------------ | ------------------ |
| `10`<br>`5`<br>`+` | `15`               |
| `10`<br>`5`<br>`*` | `50`               |

| `10`<br>`5`<br>`%` | `Neznama operacia` |
