## Cyklus while

Cyklus while opakuje telo cyklu, kým je splnená podmienka. Najprv sa vždy overí podmienka, takže sa jeho telo nemusí vykonať ani raz.

While cyklus je jednoduchý, takže asi bude stačiť len nasledovná ukážka:

```kt
fun main() {
    var number = readln().toInt()
    while (number % 2 == 0) {
        number /= 2 // delíme číslo 2, kým je párne
    }
    println(number)
}
```

## Úlohy

### 1. Odmocniny

Na štandardnom vstupe načítaj celé číslo väčšie ako 0. Ak je číslo menšie program ukonči.

Zisti (bez použitia pomocných funkcií ako `sqrt()`), či má dané číslo celočíselnú odmocninu.

Príkladmi vstupov s celočíselnou odmocninou sú: `1 -> 1`, `4 -> 2`, `9 -> 3`, `16 -> 4` ...

| Ukážka vstupu | Ukážka výstupu   |
|---------------|------------------|
| `16`          | `4`              |
| `10`          | `Nema odmocninu` |

### 2. Odpočítavanie

Na vstupe načítaj nezáporné celé číslo. Vypíš všetky čísla od neho po `0`, každé na samostatný riadok.

| Ukážka vstupu | Ukážka výstupu           |
|---------------|--------------------------|
| `3`           | `3`<br>`2`<br>`1`<br>`0` |
| `0`           | `0`                      |

### 3. Súčet do nuly

Postupne načítavaj celé čísla. Načítavanie ukonči po zadaní `0`. Vypíš súčet všetkých načítaných čísel okrem ukončujúcej nuly.

| Ukážka vstupu             | Ukážka výstupu |
|---------------------------|----------------|
| `5`<br>`-2`<br>`7`<br>`0` | `10`           |
| `0`                       | `0`            |

### 4. Počet párnych čísel

Postupne načítavaj celé čísla. Načítavanie ukonči po zadaní `0`. Zisti, koľko načítaných čísel bolo párnych. Ukončujúcu nulu nezapočítaj.

| Ukážka vstupu                     | Ukážka výstupu |
|-----------------------------------|----------------|
| `3`<br>`8`<br>`-4`<br>`11`<br>`0` | `2`            |
| `1`<br>`5`<br>`0`                 | `0`            |

### 5. Najväčšie číslo

Postupne načítavaj celé čísla. Prvé načítané číslo je vždy rôzne od `0`. Načítavanie ukonči po zadaní `0` a vypíš najväčšie zo zadaných čísel. Ukončujúcu nulu nezapočítaj.

| Ukážka vstupu                     | Ukážka výstupu |
|-----------------------------------|----------------|
| `4`<br>`12`<br>`-3`<br>`7`<br>`0` | `12`           |
| `-8`<br>`-2`<br>`-15`<br>`0`      | `-2`           |

### 6. Rozklad na cifry

Na vstupe načítaj kladné celé číslo. Pomocou cyklu `while` vypíš jeho cifry v opačnom poradí, každú na samostatný riadok.

| Ukážka vstupu | Ukážka výstupu    |
|---------------|-------------------|
| `583`         | `3`<br>`8`<br>`5` |
| `7`           | `7`               |

### 7. Vstup s heslom

Postupne načítavaj heslá, až kým používateľ nezadá správne heslo `kotlin123`. Pri každom nesprávnom hesle vypíš `Nespravne heslo`. Po zadaní správneho hesla vypíš `Prihlasene` a program ukonči.

| Ukážka vstupu                        | Ukážka výstupu                                         |
|--------------------------------------|--------------------------------------------------------|
| `ahoj`<br>`Kotlin123`<br>`kotlin123` | `Nespravne heslo`<br>`Nespravne heslo`<br>`Prihlasene` |
| `kotlin123`                          | `Prihlasene`                                           |

### 8. Skrátenie textu

Na vstupe načítaj text a číslo `n`. Pokiaľ je text dlhší ako `n` znakov, odstraňuj z jeho konca posledný znak. Nakoniec vypíš výsledný text.

| Ukážka vstupu          | Ukážka výstupu |
|------------------------|----------------|
| `programovanie`<br>`7` | `program`      |
| `Kotlin`<br>`10`       | `Kotlin`       |
