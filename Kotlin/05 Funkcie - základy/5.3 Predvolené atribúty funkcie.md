Niekedy sa oplatí funkcii nastaviť aj predvolené hodnoty argumentov. Pri volaní funkcie potom nie je nutné vypĺňať všetky hodnoty. Ukážka:

```kt
fun formatPrice(value: Double, currency: String = "EUR") = "$value $currency"

fun main() {
    println(formatPrice(15.2, "USD")) // "15.2 USD"
    println(formatPrice(13.4, "YEN")) // "13.4 YEN"
    println(formatPrice(10))          // "10 EUR"
}
```

Hoci to nie je nevyhnutné, obvykle obľubujeme argumenty s predvolenými hodnotami dávať na koniec zoznamu atribútov.
