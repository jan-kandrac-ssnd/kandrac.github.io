# 8.1 Dátové triedy

Dátové triedy (`data class`) sú triedy, ktoré slúžia primárne na uchovávanie dát. Kotlin nám automaticky vygeneruje užitočné funkcie ako `toString`, `equals`, `hashCode`, `copy` a `componentN`.

```kotlin
data class Person(val name: String, val age: Int)

fun main() {
    val p1 = Person("Janko", 25)
    val p2 = Person("Janko", 25)
    val p3 = p1.copy(age = 30)

    println(p1)               // Person(name=Janko, age=25)
    println(p1 == p2)         // true - porovnava podla hodnot
    println(p3)               // Person(name=Janko, age=30)
    println(p3.component1())  // Janko
    println(p3.component2())  // 30
}
```

> Bez `data` by trieda `Person` mala len defaultné `toString` z `Any`, ktorý vypíše niečo ako `Person@1a2b3c4d`.

### 8.1.1 Destrukcia
Vďaka funkciám `componentN` vieme používať deštrukciu (destructuring):

```kotlin
data class Person(val name: String, val age: Int)

fun main() {
    val person = Person("Janko", 25)
    val (name, age) = person  // destrukcia

    println(name) // Janko
    println(age)  // 25
}
```

### 8.1.2 copy
Funkcia `copy` vytvorí novú kópiu objektu s možnosťou zmeniť niektoré atribúty:

```kotlin
data class Person(val name: String, val age: Int)

fun main() {
    val original = Person("Janko", 25)
    val older = original.copy(age = 26)
    val renamed = original.copy(name = "Fero")

    println(original) // Person(name=Janko, age=25)
    println(older)    // Person(name=Janko, age=26)
    println(renamed)  // Person(name=Fero, age=25)
}
```

> Povinné atribúty (bez defaultnej hodnoty) musíme zadefinovať v primárnom konštruktore s `val` alebo `var`.

## Úlohy

### Úloha 1 - Kotlin Faker

Existuje veľmi populárna knižnica pre generovanie náhodných dát s názvom [FakerJS](https://fakerjs.dev/). Jej úlohou
je generovať dáta ako objekty, ktoré sa podobajú na reálne dáta. Napríklad kompletné
[informácie o jazyku](https://fakerjs.dev/api/location.html#language), [jedle](https://fakerjs.dev/api/food.html) alebo
[adrese](https://fakerjs.dev/api/location.html#postaladdress).

Tvojou úlohou bude vytvoriť podobnú "knižnicu" v jazyku Kotlin. Táto sa bude skladať len z jednoduchých top-level
funkcií s nasledujúcimi definciami:

```kotlin
/**
 * Nahodny jazyk. Obsahuje nazov jazyka a jeho dvoj a trojpismenkovu skratku, napr:
 * 
 * Slovak, sk, svk
 */
fun fakeLanguage() : FakeLanguage

/**
 * Nahodna adresa. Obsahuje address line 1 (obvykle ulica a cislo), address line 2 (obvykle mesto), postal code (PSC), napr:
 * 
 * addressLine1: SNP 32/44
 * addressLine2: Nova Dubnica
 * postalCode: 01851
 */
fun fakeAddress() : Address
```

Nakoniec vygeneruj CSV súbor so zoznamom 1000 náhodne vygenerovaných adries.

### Úloha 2 - CSV databáza

Otvor vo svojom programe [priložený CSV súbor](users.csv). Predpokladaj, že bude vždy spĺňať tieto vlastnosti:
1. V žiadnej bunke sa nebude nachádzať čiarka (`,`), ani dvojitá úvodzovka (`"`) 
2. Prvý riadok budú názvy stĺpcov v tomto poradí: "ID", "username", "password", "isAdmin"
3. Ostatné riadky budú obsahovať hodnoty reprezentujúce používateľov v databáze

Všetky heslá sú vygenerované algoritmom SHA-256 nasledovne:

```kotlin
import java.security.MessageDigest

fun sha256Hex(input: String): String =
    MessageDigest.getInstance("SHA-256")
        .digest(input.toByteArray(Charsets.UTF_8))
        .joinToString("") { "%02x".format(it) }
```

Implementuj:
1. celý CSV súbor si ulož do premennej ako `List<User>`, kde `User` bude tvoja vlastná dátová trieda
2. načítaj `username` a `plaintextPassword` zo štandardného vstupu
3. zisti, či existuje používateľ s daným `username` a `password`, kde `password == sha256Hex(plaintextPassword)`
4. ak používateľ s daným `username` neexistuje vypíš: `"Pouzivatel neexistuje"`
5. ak existuje používateľ s daným `username` ale `password` je neplatné vypíš: `"Chyba prihlasenia"`
6. ak existuje používateľ s daným `username` a `password` vypíš jeho ID a to, či je Admin alebo nie

Prihlasovacie údaje niektorých používateľov pre testovacie účely:
- gavin.feeney@bailey.test : 1111
- msgr.numbers.labadie@zemlak.test : 123321
- lemuel.schoen.iii@balistreri.test : princess

### Úloha 3 - rainbow tabuľka

Pre uhádnutie hesiel používajú hackeri takzvané Rainbow Tabuľky. Tieto držia zoznam často používaných hesiel aj s ich
hashmi. Takže ak poznáš Hash, v rainbow tabuľke ho rýchlo nájdeš, a zistíš heslo používateľa.

Ak chceš vidieť nejaké veľké, voľne dostupné rainbow tabuľky, pozri si túto [stránku](https://freerainbowtables.com/).

Nateraz prikladám veľmi malú tabuľku v CSV formáte: [rainbow-sha256.csv](rainbow-sha256.csv) (reálne tabuľky majú stovky GB). Zisti, sa či pomocou nej vieš
nabúrať do niektorých používateľských účtov z úlohy 2. Vypíš emaily kompromitovaných účov a ich heslá v plaintext
formáte.

Svoje riešenie si môžeš overiť voči tejto tabuľke kompromitovateľných používateľov: [compromised.csv](compromised.csv)
