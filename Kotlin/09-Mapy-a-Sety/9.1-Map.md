# 9.1 Mapy

Mapa (`Map`) je dátová štruktúra, ktorá ukladá dvojice kľúč - hodnota. Každý kľúč je unikátny a má priradenú jednu
hodnotu.

```kotlin
fun main() {
    val map1: Map<String, Int> = mapOf("Janko" to 25, "Fero" to 30)
    val map2: Map<String, Int> = emptyMap()
    val map3: MutableMap<String, Int> = mutableMapOf("Janko" to 25)
    val map4: MutableMap<String, Int> = mutableMapOf()

    println(map1["Janko"])    // 25
    println(map1["Marek"])    // null - neexistujuci kluc
    println(map1.getOrDefault("Marek", 0)) // 0

    map3["Fero"] = 30         // pridanie noveho paru
    map3["Janko"] = 26        // zmena existujucej hodnoty
    map3 += "Lukas" to 22     // pridanie cez operator +=
    map3.remove("Fero")       // odstranenie podla kluca

    println(map3)             // {Janko=26, Lukas=22}
}
```

> Zápis `"kľúč" to hodnota` je skrátený zápis pre vytvorenie dvojice (`Pair`).

### 9.1.1 Iterácia nad mapou

```kotlin
fun main() {
    val map = mapOf("Janko" to 25, "Fero" to 30, "Marek" to 20)

    for ((name, age) in map) {
        println("$name ma $age rokov")
    }

    map.keys.forEach { key -> println(key) }       // vsetky kluce
    map.values.forEach { value -> println(value) } // vsetky hodnoty
}
```

### 9.1.2 Priemerne hodnoty z mapy

```kotlin
fun main() {
    val známky = mapOf("Matika" to 1, "Fyzika" to 2, "Angličtina" to 1)
    val priemer = známky.values.average()
    println("Priemer: $priemer") // Priemer: 1.333...
}
```

### Úloha 3 - JSON - náročná

Jedným z klasických prípadov použitia máp sú JSON-y. Pozri si ukážku JSON-u:

```json
{
  "page": 0,
  "pages": 8,
  "data": [
    {
      "name": "VizGhar",
      "avatar": "https://avatars.githubusercontent.com/u/4579792?v=4"
    },
    {
      "name": "Linus",
      "avatar": "https://avatars.githubusercontent.com/u/4579792?v=4"
    }
  ]
}
```

Napríklad tento JSON sa dá reprezentovať ako mapa, kde kľúče budú:
`page`, `pages` a `data` a hodnoty budú 2 celé čísla a zoznam (`List`) ďalších máp s kľúčami `name` a `avatar`.

Napíš funkciu, ktorá z mapy vytvorí JSON, bez nutnosti formátovania:

```kotlin
fun jsonify(map: Map<String, Any>): String { // Any moze byt akykolvek zakladny typ + list, alebo dalsia mapa
    // preiteruj vsetky kluce+hodnoty
    var result = "{"
    for ((key, value) in map) {
        result += "\"$key\": "

        // handle different value types
        when {
            value is Int -> {}
            value is Long -> {}
            // ...
            // object handling
            value is Map<*, *> -> {
                result += jsonify(value as Map<String, Any>)
            }
            // list handling
            value is List<*> -> {
                for (item in value) {
                    // volaj tento when rekurzivne :/
                }
            }
        }
    }
    result += "}"
    return result
}

fun main() {
    val json = jsonify(
        mapOf(
            "page" to 0,
            "pages" to 8,
            "data" to listOf(
                mapOf(
                    "name" to "VizGhar",
                    "avatar" to "https://avatars.githubusercontent.com/u/4579792?v=4"
                ),
                mapOf(
                    "name" to "Linus",
                    "avatar" to "https://avatars.githubusercontent.com/u/4579792?v=4"
                )
            )
        )
    )

    println(json)
}

```
