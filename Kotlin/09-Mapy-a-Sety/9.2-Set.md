# 9.2 Sety

Set (`Set`) je množina unikátnych hodnôt. Na rozdiel od `List` nemá definovaný poradie a každá hodnota sa v ňom nachádza nanajvýš raz.

```kotlin
fun main() {
    val set1: Set<Int> = setOf(1, 2, 3, 3, 2)  // {1, 2, 3} - duplicitne odstranene
    val set2: Set<Int> = emptySet()
    val set3: MutableSet<Int> = mutableSetOf(1, 2, 3)
    val set4: MutableSet<Int> = mutableSetOf()

    set3.add(4)            // pridanie prvku
    set3 += 5              // pridanie cez operator
    set3.remove(2)         // odstranenie prvku

    println(set3)          // [1, 3, 4, 5]
    println(3 in set3)     // true - overenie existencie
    println(2 in set3)     // false
}
```

### 9.2.1 Operácie nad setmi
Sety podporujú matematické operácie - pretínanie, zlučovanie a rozdiel:

```kotlin
fun main() {
    val setA = setOf(1, 2, 3, 4)
    val setB = setOf(3, 4, 5, 6)

    val prienik = setA.intersect(setB)       // {3, 4}
    val zlucenie = setA.union(setB)           // {1, 2, 3, 4, 5, 6}
    val rozdiel = setA.subtract(setB)         // {1, 2}
    val rozdiel2 = setB.subtract(setA)        // {5, 6}

    println(prienik)    // [3, 4]
    println(zlucenie)   // [1, 2, 3, 4, 5, 6]
    println(rozdiel)    // [1, 2]
}
```

### Úloha 1 - Turniket

Do školy vstupujú ľudia pomocou kariet s kódom. Systém ale neoveruje, či človek s daným kódom už náhodou nevstúpil do
budovy. Študenti tento systém zneužívali a na jednu kartu sa do školy dokázali dostať viacerí naraz.

Naprogramuj systém, aby vyhlásil chybu, ak sa človek s chce dostať do vnútra neoprávnene:

1. Na štandardnom vstupe načítavaj v nekonečnom cykle riadok s dvoma slovami: `action` a `cardNumber`
2. Ak `action` = `enter`, tak sa do budovy pokúša vstúpiť človek s `cardNumber`
3. Ak `action` = `exit`, tak sa z budovy pokúša vystúpiť človek s `cardNumber`
4. Ak `action` = `report`, tak ignoruj `cardNumber` a vypíš čiarkou oddelený zoznam všetkých `cardNumber` v budove
5. Ak `action` nie je ani jedno z vyššie spomenutých, ukonči program
