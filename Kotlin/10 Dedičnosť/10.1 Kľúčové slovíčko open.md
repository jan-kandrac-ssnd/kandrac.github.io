Všetky triedy v Kotline sú implicitne `final`, čo znamená, že z nich nemôžeme dediť. Ak chceme z triedy dediť, musíme ju označiť kľúčovým slovom `open`:

```kt
open class Animal {
    fun breathe() {
        println("Dycham")
    }
}

class Dog : Animal() {
    fun bark() {
        println("Hav!")
    }
}

fun main() {
    val dog = Dog()
    dog.breathe()  // Dycham
    dog.bark()     // Hav!
}
```

> Bez `open` by trieda `Animal` bola `final` a pokus o dedičnosť `class Dog : Animal()` by spôsobil chybu kompilácie.

### 10.1.1 Prečo `final`?
Kotlin používa `final` ako predvolené nastavenie z bezpečnostných dôvodov. Ak chceme dediť, musíme sa explicitne rozhodnúť pomocou `open`. Toto je rozdiel oproti napríklad Jave, kde sú triedy `open` implicitne.
