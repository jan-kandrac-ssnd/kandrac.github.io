Gradle je build systém používaný v väčšine Kotlin a Android projektov. V IntelliJ Idea ho vieme vytvoriť priamo:

1. *File → New → Project*
2. Zvoľ *Gradle* ako Build system
3. Zvoľ *Kotlin* ako Language
4. Zvoľ JDK 21
5. Klikni *Create*

IntelliJ nám automaticky vytvorí súbor `build.gradle.kts` (Kotlin DSL) a adresárovú štruktúru:

```
MyProject/
├── build.gradle.kts     // konfiguracia projektu
├── settings.gradle.kts  // nastavenia projektu
└── src/
    └── main/
        └── kotlin/
            └── Main.kt
```

### 14.1.1 Základná štruktúra build.gradle.kts

```kotlin
plugins {
    kotlin("jvm") version "2.0.21"
    application
}

repositories {
    mavenCentral()
}

dependencies {
    // sem pridame zavislosti (knižnice)
}

application {
    mainClass.set("MainKt")
}
```

> `plugins` - aké pluginy používame (Kotlin JVM, application)
> `repositories` - odkiaľ sťahujeme knižnice (mavenCentral je najčastejšie)
> `dependencies` - aké knižnice potrebujeme

### 14.1.2 Spustenie projektu
V IDEA klikni na zelenú šípku vedľa funkcie `main` alebo použi terminál:

```bash
./gradlew run
```

> `gradlew` (Gradle Wrapper) je skript, ktorý sa postará o stiahnutie správnej verzie Gradle.
