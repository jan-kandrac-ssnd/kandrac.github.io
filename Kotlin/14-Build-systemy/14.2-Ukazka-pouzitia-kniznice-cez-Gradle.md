Ukážme si, ako pridať knižnicu do projektu a použiť ju. Pridáme knižnicu `Gson` pre prácu s JSON:

### 14.2.1 Pridanie závislosti
V súbore `build.gradle.kts` pridáme do bloku `dependencies`:

```kotlin
dependencies {
    implementation("com.google.code.gson:gson:2.11.0")
}
```

Po uložení súboru IntelliJ automaticky stiahne knižnicu. Ak nie, klikni na *Load Gradle Changes* (ikona slona vpravo hore).

### 14.2.2 Použitie knižnice
Teraz môžeme Gson používať v našom kóde:

```kt
import com.google.gson.Gson

data class Person(val name: String, val age: Int)

fun main() {
    val gson = Gson()

    // Objekt na JSON string
    val person = Person("Janko", 25)
    val json = gson.toJson(person)
    println(json) // {"name":"Janko","age":25}

    // JSON string na objekt
    val parsed = gson.fromJson(json, Person::class.java)
    println(parsed) // Person(name=Janko, age=25)
}
```

### 14.2.3 Ďalšie užitočné knižnice
Tu sú niektoré knižnice, ktoré sa často používajú:

| Knižnica | Účel |
| -------- | ---- |
| `kotlinx-coroutines` | Asynchrónne programovanie |
| `kotlinx-serialization` | Serializácia (alternatíva k Gson) |
| `okhttp` | HTTP klient |
| `JUnit` | Testovanie |
